# flat UX와 데스크톱 탭 그룹

세션·창 표시·창별 에이전트 집계·호스트 연결 메뉴는 [SESSION_HIERARCHY.md](SESSION_HIERARCHY.md)를 따른다.

Android와 Windows·Mac 공통 GPUI 코드에 적용하며 기존 설정·호스트 ID·플랫폼별 자격 증명 저장소와 Windows 빌드·패키징 진입점을 유지한다.

## 조작과 상태

- 회색 바탕·파란 강조색의 평평한 목록과 얇은 구분선을 사용한다. 시스템·밝게·어둡게 테마는 유지하며 데스크톱 입력창·선택·포커스도 테마를 따른다.
- 데스크톱 왼쪽 탐색기는 호스트와 활성 그룹의 세션 → 창 트리를 함께 보여준다. Android는 호스트 목록과 tmux 관리 시트를 유지한다. Android 터치 항목은 최소 48dp를 확보한다.
- Windows·macOS 호스트는 최초 연결 시작 순서로 놓고 미연결 호스트는 저장된 배열 순서로 아래에 둔다. 즐겨찾기·최근 접속·연결 완료·실패·복구·상태 갱신은 재정렬하지 않는다. 호스트 행 드래그는 삽입 위치를 표시하고 드롭할 때 전체 순서를 확정·저장한다. Esc나 목록 밖 드롭은 취소한다. 수동 순서는 이후 연결보다 우선하고 새 호스트는 끝에 추가하며 편집·동기화는 기존 위치를 유지한다.
- 데스크톱 복원·재접속 상태는 창 하단 상태줄에 표시한다. 기존 세션 목록 위에 대기 행을 삽입하지 않아 목록 위치·펼침·스크롤을 유지하며, 목록이 비어 있을 때만 대기 안내를 표시한다. 복구 중 대상 선택·터미널 입력 차단은 유지한다.
- 데스크톱 알림 `🔔`과 설정 `⚙️`은 전체 창 하단의 26px 상태줄 오른쪽에 이 순서로 고정한다. 긴 상태 문구는 말줄임하고 툴팁으로 전체 내용을 확인한다. 알림의 미확인 개수는 작은 배지(100개 이상은 `99+`)로 표시하며, 두 버튼은 기능 이름 툴팁을 제공한다. Android 버튼 배치는 유지한다.
- 펼침 화살표는 탐색만 하고 행 이름은 대상 선택을 수행한다. 헤더 `+`와 행 `…` 메뉴에 생성·이름 변경·삭제를 배치한다. 삭제 확인은 유지한다.
- `↻`는 세션 새로고침이며 완료 요청 ID로 중복 요청을 차단한다. Android는 `세션 새로고침` 접근성 설명과 툴팁, GPUI는 같은 컨트롤 ID와 툴팁을 사용한다.
- tmux 도구 모음은 각 터미널 상단에 별도로 둔다. `패널 분할`, `이동`, `크기 조절`, `닫기`로 묶으며, 방향별 이동은 원격 선택 패널과 입력 대상을 함께 바꾸고 크기 조절은 3셀 단위다. 닫기는 기존 확인창을 거친다. 데스크톱의 각 도구 모음은 해당 그룹의 선택 탭에 적용하며 클릭 시 최신 연결 상태·패널을 확인한다. Android 도구는 가로 스크롤, 닫기 버튼은 오른쪽 고정이며 터치 영역은 48dp다. 탭 바의 `화면 분할`은 앱 그룹, 터미널 위 `패널 분할`은 원격 tmux 작업이다.
- 데스크톱 각 그룹은 독립된 탭 순서와 선택 탭을 가진다. 탭 바 오른쪽 끝의 `↔️ / ↕️` 버튼으로 만든 분할은 빈 그룹이며 새 연결은 활성 그룹에 열린다. 버튼은 탭 목록 스크롤 영역 밖에 고정하고 기능 이름을 툴팁으로 표시한다. 동일 호스트 연결도 별도 SSH 핸들을 사용한다.
- 호스트 ID·tmux 세션 ID마다 탭 하나를 유지한다. 비동기 연결·대상 선택 전에 세션 ID를 예약하고, 같은 세션을 누르면 모든 그룹에서 찾아 기존 위치를 선택하고 터미널에 포커스를 준다. 최초 연결의 세션 미선택 탭을 먼저 재사용하며 다른 세션은 활성 그룹에 연다. 재선택은 창·pane을 유지하고 창 행은 해당 세션 탭에서 전환한다. 호스트 이름은 마지막으로 활성화한 해당 호스트 탭으로 이동한다. 연결 중·복구 중·실패 상태도 검색하며 원격 조작은 복구 중 차단한다. 재접속은 대상 세션을 유지하고 닫힌 탭은 다음 선택에 새로 연다. 알림도 같은 경로를 사용하며 세대·원격 대상 검증을 유지한다. 제목은 별칭·세션명을 함께 표시하고 이름 변경은 ID를 바꾸지 않는다.
- 탭 제목을 탭 바에 드롭하면 순서를, 다른 그룹 중앙에 드롭하면 소속 그룹을 바꾼다. 그룹 본문의 네 가장자리에 드롭하면 해당 방향에 새 그룹을 만들고 탭을 옮긴다. 드래그 중 실제로 분할 가능한 방향에만 반투명 예상 배치를 표시한다. 자기 그룹의 유일한 탭, 빈 대상 그룹, 최소 공간 부족·최대 그룹 수 도달 시에는 분할하지 않는다. Esc 또는 그룹 밖 드롭은 배치를 바꾸지 않는다. `…` 메뉴에서도 순서·소속 그룹을 바꾼다. 연결과 터미널 Entity를 재생성하지 않는다. 같은 패널의 크기 변경 snapshot은 로컬 스크롤 기록과 위치를 유지한다.
- 마지막 탭을 닫아도 그룹은 유지한다. `그룹 합치기`는 분할 트리의 인접 그룹에 탭을 옮긴 뒤 그룹을 제거한다. 닫기는 해당 연결만 종료한다.
- 경계를 드래그하여 비율을 조절한다. 그룹의 최소 분할 공간은 280×180 논리 픽셀이며 최대 16개 그룹을 지원한다. 창이 작아지면 기존 그룹은 축소 표시하고 추가 분할을 막는다.
- 키보드의 기존 연결 단축키와 하단 단축키 바는 활성 그룹의 선택 탭에 적용한다. 각 그룹의 선택 연결에 있는 창 컨테이너만 클라이언트 크기를 요청한다. 크기 요청은 연결당 한 건만 진행하고 대기 중 변경은 최신 크기로 병합한다.

## 모달과 저장

호스트 입력창에는 비밀번호·키 암호의 `비밀번호 표시` 체크가 있다. 표시 상태는 저장하지 않고 새 입력창에서 숨김으로 시작한다. 데스크톱 개인키 경로의 빈 입력에는 macOS `$HOME/.ssh/`, Windows `%USERPROFILE%\.ssh\`의 실제 사용자 경로를 플레이스홀더로 보여준다.

대화상자는 공통 포커스 링과 마우스 차단 레이어를 사용한다. 첫 입력 항목으로 이동하며 Tab·Shift+Tab은 보이는 입력과 버튼을 순환한다. 입력 없는 확인/설정 창은 버튼에서 시작한다. 버튼은 Enter/Space, 이름 입력은 Enter로 실행하며 IME 조합 중 Enter는 제출하지 않는다. Esc와 닫기는 이전 포커스를 복원한다. 배경 터미널은 모달 동안 입력·마우스·스크롤을 차단하며 일반 터미널의 Tab 전송은 유지한다.

설정 디렉터리는 `desktop/src/platform.rs`의 기존 경로를 사용한다. 새 `workspace-layout.json`에는 `Group { id }`와 재귀 `Split { axis, ratio, first, second }`만 기록한다. 호스트·탭·자격 증명·선택 상태는 저장하지 않는다. 재실행 시 모든 그룹은 비고 연결은 사용자가 다시 연다. 잘못된 JSON, 중복 그룹 ID, 범위 밖 비율, 과대한 파일/깊이는 빈 단일 그룹으로 대체한다. 기존 `settings.json`은 그대로 읽는다.

`host-order.json`은 호스트 ID 전체 순서와 최초 연결 시작 구간·수동 배치 여부를 기기에만 저장한다.
삭제된 ID를 정리하고 새 ID를 뒤에 붙인다. 없거나 잘못된 파일은 저장된 호스트 배열 순서로 대체한다.
공통 설정·클라우드 형식과 코어·UniFFI API는 바꾸지 않으며 Android 정렬·탭 동작은 이번 변경에 포함하지 않는다.

코어 인터페이스는 [CORE_API.md](CORE_API.md)의 `selectTarget`·`focusPane` 확장을 따른다. 방향 이동은 [tmux 3.3a의 select-pane 구현](https://raw.githubusercontent.com/tmux/tmux/3.3a/cmd-select-pane.c)의 방향 플래그를 사용한다. 이동 뒤 실제 활성 패널을 조회하고 화면·PaneTarget·패널 세대를 갱신한다. 같은 세션에 연결한 다른 클라이언트의 창·pane 선택도 반영한다. pane별 출력 세대는 입력 포커스와 독립적으로 유지한다.

## 검증 범위

단위 검사는 연결 시작 순서·수동 배치 우선순위·삭제/추가·잘못된 순서 파일·세션 ID 예약을 검사합니다.
GPUI 자동화는 호스트 드래그 확정/취소·순서 재로드·세션 반복 선택·그룹 이동·연결/터미널 Entity 유지와 기존 포커스·모달·탭 이동·그룹 배치 저장을 검사합니다.

GPUI 0.2.2의 OS 접근성 트리 지원 한계로 네이티브 스크린리더 검증은 완료되지 않았습니다.
