# 사용 안내

DGL은 SSH 호스트와 tmux 세션·창·pane을 GUI로 관리합니다.
설치·빌드 경로는 [README](../README.md)와 [개발 안내](DEVELOPMENT.md)를 참고하세요.

설정에서 밝기 테마와 **시스템 / DGL 기본 / 사용자 지정** 강조 색상을 각각 선택합니다.
색상 프리셋·HEX 입력과 플랫폼별 제목 표시줄 동작은 [앱 스타일](APPEARANCE.md)에 있습니다.

설정의 **언어 / Language**에서 **시스템 / 한국어 / English**를 선택합니다. 기본은 시스템 언어이며
한국어 시스템에서는 한국어, 그 외에는 영어를 사용합니다. 변경은 바로 적용하고 기기에 저장하며
클라우드로 공유하지 않습니다. 시스템 언어는 앱 시작과 Android 앱 복귀 시 다시 확인합니다.
호스트 별칭·원격 세션명·터미널 출력·사용자가 작성한 입력과 외부 도구의 진단 원문은 번역하지 않습니다.
데스크톱 제목 표시줄에는 `DGL`을 표시합니다.

## 연결과 재접속

1. 원격 서버에 SSH와 tmux를 설치하고 UTF-8 로케일을 구성합니다.
2. 호스트·포트·사용자와 인증 정보를 저장합니다. 비밀번호 또는 개인키를 사용할 수 있습니다.
3. 처음 연결할 때 SHA-256 호스트키 지문을 서버에서 독립적으로 확인하고 신뢰합니다.
4. 기존 tmux 세션을 선택하거나 새 세션을 만듭니다.

네트워크 오류는 **2·4·8·16·30·30·30초 간격으로 최대 7회** 자동 재시도합니다.
횟수를 소진해도 연결 탭·접속 정보·인증 정보·신뢰 지문과 마지막 tmux 대상을 유지합니다.
`새로고침 재시도`는 즉시 접속하고 재시도 횟수를 새로 시작합니다.
`재시도 정지`는 진행 중인 접속과 예약된 재시도를 멈춥니다. 연결 성공 후에도 횟수를 초기화합니다.
호스트키 변경·인증 실패는 자동 재시도하지 않으며 수동 재시도도 지문 검증을 생략하지 않습니다.

이 복구는 앱과 연결 탭이 유지되는 동안 적용됩니다. 서버에 tmux 세션이 남아 있으면 다시 연결하고
서버의 현재 창·활성 pane을 따릅니다. 앱 재실행 시 SSH는 자동 연결하지 않습니다.
일반 SSH 셸에서는 연결 종료 뒤 기존 프로세스 보존을 보장하지 않습니다.

선택된 호스트의 연결 메뉴에서 `재접속`·`연결 종료`를 사용할 수 있습니다.
**연결 종료는 SSH와 tmux 클라이언트만 닫고, 삭제는 확인 후 원격 대상을 종료합니다.**

## 호스트와 인증

호스트에 별칭·즐겨찾기를 설정하고 최근 접속을 확인할 수 있습니다.
데스크톱 호스트는 처음 연결을 시작한 순서로 표시하며 미연결 호스트는 저장된 목록 순서로 아래에 놓습니다.
접속 성공·실패·재접속·즐겨찾기 변경은 순서를 바꾸지 않습니다. 호스트 행을 끌면 삽입 위치가 표시되고,
놓은 전체 순서를 이 기기에 저장합니다. Esc나 목록 밖 드롭은 취소합니다. 수동 정렬 뒤 새 호스트는 끝에 추가됩니다.
비밀번호, RSA/Ed25519 개인키와 암호화된 개인키를 지원하며 Ed25519 생성·공개키 복사도 제공합니다.

데스크톱의 개인키 `파일 선택…`은 기본 SSH 폴더(macOS `~/.ssh`, Windows `%USERPROFILE%\.ssh`)를 엽니다.
빈 경로에서 `경로에서 가져오기`를 눌러도 선택창을 엽니다. 폴더를 입력하면 그 안에서 선택하고,
파일 경로를 입력하면 직접 가져옵니다. 비밀번호·키 암호의 표시 여부는 저장하지 않습니다.
오류별 안내는 [호스트 인증](HOST_AUTH.md), 기기 간 설정 공유는 [클라우드 동기화](CLOUD_SYNC.md)에 있습니다.

## tmux 세션·창·pane

데스크톱 왼쪽 탐색기와 Android `tmux 관리` 시트에서 **세션 → 창** 목록을 봅니다.
`▸`는 펼침, 이름 클릭은 선택, `+`는 세션 생성, `↻`는 목록 새로고침입니다.
행별 `…`에서 창 생성·이름 변경·삭제를 실행합니다. 단일 창은 기본으로 세션 행에 합쳐 표시하며,
설정의 `단일 창도 표시`로 별도 창 행을 볼 수 있습니다.

창을 선택하면 보이는 pane 전체를 실제 tmux 좌표·열/행대로 표시합니다.
pane 클릭은 입력 포커스를 바꾸며, 일반 SSH 클라이언트의 창·pane 변경도 반영합니다.
터미널 위 도구 모음의 ↔/↕는 pane 분할, 방향키는 포커스 이동, 크기 조절은 3셀 단위입니다.
경계 드래그도 지원하며 `닫기 ×`는 확인 후 선택 pane을 종료합니다.
일반 SSH 셸·재연결 중에는 사용할 수 없는 pane 도구를 비활성화합니다.

서버의 `tmux new-session`, `tmux attach`, `tmux list-sessions`를 계속 사용할 수 있습니다.
DGL은 tmux 전역 설정·사용자 셸·키 바인딩을 바꾸지 않습니다.
[계층 표시](SESSION_HIERARCHY.md)와 [창 동기화·범위](TMUX_WINDOW_SYNC.md)에 자세한 규칙이 있습니다.

## 데스크톱 탭과 화면 분할

탭 바 오른쪽 `↔️ / ↕️`는 빈 탭 그룹을 만듭니다. 새 연결은 활성 그룹에 열립니다.
같은 호스트 ID·tmux 세션 ID의 탭은 모든 그룹에서 하나만 유지합니다. 세션을 다시 누르면 기존 탭과
소속 그룹으로 이동하고 현재 창·pane과 연결을 유지합니다. 창 행은 해당 세션 탭의 창을 전환합니다.
첫 호스트 연결의 세션 미선택 탭은 첫 세션 선택에 재사용하고, 다른 세션은 별도 SSH 연결의 탭으로 엽니다.
호스트 이름은 마지막으로 활성화한 해당 호스트 탭으로 이동하며, 열린 탭이 없으면 연결합니다.
연결 중·재접속 중·실패한 탭도 재사용하며, 닫은 탭은 다음 선택 때 새로 엽니다.
탭 제목은 호스트 별칭과 세션명을 함께 표시하고 이름 변경 후에도 세션 ID는 유지합니다.
탭을 다른 탭 위로 끌면 순서 변경, 그룹 중앙으로 끌면 이동, 가장자리로 끌면 미리보기 방향으로 분할합니다.
Esc로 취소하고 `…` 메뉴로도 이동할 수 있습니다. 경계 드래그로 비율을 조절하며 `🔗`는 인접 그룹과 합칩니다.
마지막 탭을 닫아도 빈 그룹은 남습니다. 최대 16개 그룹이며 공간이 부족하면 추가 분할을 막습니다.

`workspace-layout.json`은 그룹 구조·비율만 저장합니다. 재실행 시 빈 그룹으로 시작합니다.
호스트 순서는 같은 설정 디렉터리의 기기 전용 `host-order.json`에 저장하며 클라우드로 동기화하지 않습니다.
순서 파일이 없거나 잘못되었으면 저장된 호스트 배열 순서로 시작합니다.
앱의 화면 분할과 원격 tmux pane 분할은 별개입니다. [작업 공간 안내](UX_WORKSPACE.md)를 참고하세요.

## 키보드·텍스트 작성

하단 단축키 바는 설정에서 표시할 키를 고르고 기본값으로 복원할 수 있습니다.
데스크톱은 휠·트랙패드·원격 마우스 보고·조합 키를 처리하며 Shift+마우스는 로컬 선택·스크롤에 사용합니다.
대화상자는 Tab/Shift+Tab으로 이동하고 Esc로 닫습니다. IME 조합 중 Enter는 제출하지 않습니다.

데스크톱 입력 도구는 오른쪽 터미널 아래에 하나만 표시하며 활성 그룹의 선택 탭에 적용합니다.
왼쪽 `텍스트 작성`과 오른쪽 CLI 메뉴는 고정하고 가운데 단축키만 가로 스크롤합니다.
Android 하단의 키보드 버튼은 IME를 열고 닫습니다. 두 플랫폼의 `텍스트 작성`에서 여러 줄·한글·이모지를 편집하고
`전송`으로 보냅니다. Enter 키는 줄바꿈이며 `Enter 함께 보내기`는 기본 꺼짐입니다.
초안은 연결별 메모리에 유지하고 전송 성공·연결 제거·앱 종료 시 비웁니다. 실패한 입력은 자동 재전송하지 않습니다.
취소 후 다시 열면 초안·선택 위치·Enter 옵션을 복원합니다. 연결·세션·pane이 바뀌면 전송을 거부하고 초안을 유지하므로 다시 열어 대상을 확인하세요.

설정에서 볼륨 위·아래 키에 기본 음량 조절, 단축키, 텍스트/키 매크로를 각각 지정할 수 있습니다.
기본은 꺼짐이며 터미널이 보이고 입력 가능할 때 한 번 실행합니다. 대화상자·호스트 목록·연결 복구 중에는
기본 음량 조절을 사용합니다. 빈 매크로와 UTF-8 64 KiB 초과 입력은 허용하지 않습니다.

Android 상단 분할 아이콘은 pane 도구 모음을 접거나 펼칩니다.
키보드 크기 변경은 마지막 변경 이후 150ms로 모으고, 화면 복원 시 이전 화면을 잠시 유지합니다.
선택형 `부드러운 터미널 화면 전환`은 기본 꺼짐이며 시스템 동작 줄이기 설정을 따릅니다.
전송·초안·입력 프로토콜의 범위는 [터미널 입력](TERMINAL_INPUT.md)에 있습니다.

## CLI 실행과 알림

하단 `…`에서 Claude Code·Codex·AGY·Grok Build를 실행할 수 있습니다.
일반 실행과 번개 `Bypass` 실행은 각각 선택한 명령과 Enter를 활성 터미널에 한 번 보냅니다.
Bypass는 해당 CLI의 권한 확인을 건너뛰는 옵션입니다. CLI 설치·로그인은 원격 환경에서 준비해야 합니다.
AGY·Grok Build의 `test` 표시는 실험 지원을 뜻합니다.

프로세스 아이콘은 기본 탐지로 표시합니다. 호스트 메뉴의 `에이전트 상태 연동`은 변경 내용을 검사한 뒤
선택적으로 도우미·공식 훅을 설치하며 기존 사용자 훅을 보존합니다.
질문·승인·응답 종료·오류는 발생한 사건을 뜻하며 현재 대기나 작업 성공을 보장하지 않습니다.
OS 알림은 설정에서 켜고 Android는 앱 프로세스와 SSH 연결이 유지되는 동안 수신합니다.
명령·버전·서비스별 수집/설치·실제 확인 범위는 [에이전트 상태](AGENT_STATUS.md)를 따릅니다.

## tmux 탐지 문제

tmux는 SSH 기본 PATH, 로그인 셸 PATH, 대표 설치 경로 순서로 탐지합니다.
찾은 절대 경로를 버전 확인·목록·생성·Control Mode에 함께 사용합니다.
실패 시 상태 옆 ⓘ에서 시도·경로·확인 명령을 봅니다. 미발견·실행 실패·미지원 버전·응답 오류를 구분합니다.
지원 tmux가 없으면 일반 SSH 셸로 연결됩니다.
