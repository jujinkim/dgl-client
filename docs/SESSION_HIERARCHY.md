# 세션·창 탐색과 tmux 창 표시

Mac·Windows GPUI 탐색기와 Android 대화면 탐색기·좁은 창 tmux 관리 시트는 **세션 → 창**까지만 표시한다.
어떤 표시 설정에서도 pane 행은 만들지 않는다. 창을 선택하면 보이는 pane 전체를 터미널 영역에 표시한다.

설정의 **단일 창도 표시**는 기존 `showAllHierarchy` / `show_all_hierarchy` 저장 키를 그대로 사용한다.
기본은 꺼짐이며 기기별로 저장한다. 이전 true 값은 단일 창 행을 표시하고, false 값은 세션 행과 합친다.
Drive 동기화 항목에는 추가하지 않는다.

| 구조 | 기본 표시 | 설정 켜짐 |
|---|---|---|
| 세션 → 창 1개 | 세션 행 아래 창 번호·창 이름·pane 개수 | 세션 → 창 |
| 세션 → 창 여러 개 | 세션 → 창 | 세션 → 창 |

자식이 있는 세션에만 오른쪽 펼침 화살표가 있다. 최상위 이름은 왼쪽에 맞추고 자식 창만 20px/dp 들여쓴다.
자식이 없는 행 앞에는 화살표용 빈 공간을 두지 않는다.
Android 화살표·메뉴·에이전트 상태 버튼은 48dp 영역을 유지한다.
세션·창 행의 첫 줄은 이름, 둘째 줄은 활성 pane 제목이며 창·패널 정보는 작은 배지로 구분한다.
세션은 해당 세션의 활성 창·pane을, 창은 자신의 활성 pane을 사용한다. 제어·방향 문자와 가장자리 공백을 정리하고,
pane 제목이 비었거나 이름과 같으면 생략한다. 단일 창 합침에서는 보조 줄에 원래 창 번호·이름도 표시한다.
넘치는 정보는 말줄임하고 전체 내용은 툴팁과 Android 접근성 설명으로 제공한다. 실제 tmux 이름·ID와 메뉴 대상은 바꾸지 않는다.
GUI 탭과 Android 연결 선택 목록의 첫 줄은 `세션 · 활성 창 이름 · 활성 pane_title`, 둘째 줄은 작은 호스트 배지다.
제목은 사용자에게 보이는 글자 단위로 앞 20글자까지 표시하고 초과할 때만 `…`를 붙인다. 호스트 배지는 별도 폭 제한을 둔다.
빈 창 이름·제목과 중복된 이름은 생략하며, 창·pane 전환과 원격 이름·터미널 제목 변경을 자동 반영한다.
재접속·세션 소실·Android 화면 폭 전환 중에도 마지막 이름을 유지한다. 데스크톱 툴팁과 Android 접근성 설명에는 전체 이름을 제공한다.
Android 탭의 길게 누르기는 드래그용으로 유지하며, 연결 선택 영역의 길게 누르기로 전체 이름 툴팁을 볼 수 있다.
GPUI 0.2.2의 네이티브 접근성 API 한계는 유지하며 OS 접근성 검증으로 간주하지 않는다.

세션·창 메뉴의 생성·이름 변경·삭제와 활성 pane의 분할·제목 변경·삭제 기능을 유지한다.
터미널 위 도구 모음은 현재 입력 pane의 분할·방향 이동·3셀 크기 변경·닫기에 적용한다.
에이전트 상태 버튼은 창에 속한 모든 pane을 집계한다. 합쳐진 세션 행에도 같은 창 집계를 표시한다.
상세에서는 각 관측의 실제 pane으로 이동할 수 있고, 설치·관리는 호스트 메뉴에 둔다.

데스크톱·Android 대화면 하단 상태줄은 호스트 배지와 연결 단계·대상을 구분해 표시한다.
Android 좁은 창 상단은 세션명(최대 20글자)과 호스트 배지만 표시하고 정상 연결 상태·대상을 반복하지 않는다.
현재 연결의 `…` 메뉴에 `tmux 관리`와 패널 도구 표시 전환을 두며 별도의 관리 줄은 표시하지 않는다.
연결 중·재접속·실패·세션 소실·일반 SSH 안내와 필요한 재시도·정지 기능은 유지한다.
내부 ID는 진단 정보에만 표시한다. 같은 세션의 외부 창·pane 선택은 입력 대상에 반영하며,
외부 클라이언트가 다른 세션으로 이동한 것까지 따라가지 않는다.

## 데이터와 갱신

`RemoteWindow`는 창 번호·이름·실제 열/행·일반/보이는 layout·확대 상태를 보존한다.
`RemotePane`은 제목·명령·모드·열/행·left/top 좌표를 보존한다.
서버 상태줄이나 화면 문자열을 분석해 배치를 추정하지 않는다.

Control Mode의 layout·창/pane 변경 알림과 `dgl-metadata` format 구독으로 목록을 갱신한다.
프로그램의 OSC 0/2 터미널 제목도 tmux의 `pane_title` 변경으로 수신한다. 구독은 모든 세션의
창·pane을 포함하며 tmux가 최대 초당 1회 `%subscription-changed`를 보낸다.
tmux 세션 연결을 유지하는 동안 전면·백그라운드나 렌더러 출력 구독 유무와 무관하게 메타데이터를 처리한다.
별도 주기 폴링·사용자 훅 설치·tmux 전역 설정 변경은 추가하지 않는다.
제목·이름·프로세스 갱신은 출력 화면을 재캡처하지 않는다. pane 클릭은 입력 포커스만 바꾼다.
신규/크기·모드 변경 pane, 연결 복구·렌더러 재생성 또는 출력 지연으로 복원이 필요한 pane만 캡처한다.
같은 창의 영향받지 않은 pane은 출력 세대·에뮬레이터·로컬 기록을 유지한다.

자세한 출력·크기·수명 계약은 [TMUX_WINDOW_SYNC.md](TMUX_WINDOW_SYNC.md)를 따른다.

## 검증

공통 표시 기대값은 `fixtures/migration/hierarchy-v2.json`, wire·저장 호환은 `contract-v1.json`에 있다.
Rust와 Kotlin이 같은 fixture를 읽고, GPUI 자동화와 Android 계측이 pane 행 부재·창 집계·메뉴·펼침을 검사한다.
격리 SSH/tmux의 실행 결과와 실제 기기 제외 범위는 [VALIDATION.md](VALIDATION.md)를 따른다.
