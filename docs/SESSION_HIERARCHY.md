# 세션·창·패널 제목 표시

Mac·Windows의 GPUI 탐색기와 Android의 tmux 관리 시트는 같은 계층을 표시한다.

| 항목 | 제목 | 보조 정보 |
|---|---|---|
| 세션 | 실제 tmux 세션명 | 창 개수 · 패널 개수 |
| 창 | 그 창의 활성 패널 터미널 제목 | 세션명 · 창 번호: 실제 창 이름 / 프로세스명 · 패널 개수 |
| 패널 | 그 패널의 터미널 제목 | 패널 ID · 프로세스명 · 크기 · 해당하는 경우 copy-mode |

세션·창 제목은 16px/sp 굵게, 패널 제목은 14px/sp 중간 굵기로 두 줄까지 표시한다.
보조 정보는 12px/sp 한 줄이며 넘치면 말줄임한다. 시간은 표시하지 않는다.
창의 활성 패널 제목이 비어 있으면 실제 창 이름을, 패널 제목이 비어 있으면 프로세스명과 ID를 쓴다.
제목을 눌러 선택하고 화살표로 펼치거나 접는다. 선택 강조·세션 배경·들여쓰기·메뉴·에이전트 배지는 유지한다.

데스크톱 툴팁과 Android의 툴팁·접근성 이름은 줄임 없는 전체 제목과 보조 정보를 담는다.
현재 GPUI 0.2.2에는 네이티브 접근성 이름 API가 없어 Mac VoiceOver·Windows UIA에
행의 접근성 이름을 제공하는 부분은 미구현이다. 툴팁을 네이티브 접근성 지원으로 간주하지 않는다.

## 데이터와 갱신

`RemotePane.title`은 tmux `pane_title`, `RemoteWindow.index`는 `window_index`다.
`pane_current_command`, 실제 세션명과 창 이름도 별도로 보존한다. 상태바·터미널 화면 문자열은 분석하지 않는다.
tmux 실행에 `-u`를 사용해 SSH 서버의 locale과 무관하게 Unicode를 전달한다.
구분자·역슬래시는 tmux `q:`로 보호하고, 제목의 제어문자는 조회와 화면 표시 단계에서 정리한다.
tmux 3.7의 자체 제목 정리 결과(예: 역슬래시 표현)는 서버가 제공한 그대로 보존한다.

세션에 접속하면 Control Mode 클라이언트에 `dgl-metadata` format 구독을 등록한다.
중첩 `S:`/`W:`/`P:` format으로 다른 세션과 숨겨진 창·패널까지 감시한다.
`%*`만 구독하면 접속한 세션만 감시하므로 사용하지 않는다. 변경 알림은 tmux의 최대 초당 1회 주기를 따른다.
알림 값 자체를 레코드로 해석하지 않고 같은 목록 조회로 최신 상태를 읽는다.
최초 목록·수동 새로고침·재접속에도 같은 필드를 조회하며, 재접속 시 구독도 다시 등록한다.
아직 세션을 선택하지 않은 목록 화면에서는 최초 조회와 수동 새로고침을 사용한다.

제목·이름·프로세스·외부 활성 패널 변경은 상태 목록만 갱신한다. 입력 대상 ID와 세대,
터미널 출력 구독·로컬 선택·스크롤·포커스·펼침 상태를 바꾸지 않는다.
선택 패널의 크기·모드가 변하면 화면을 복원하며, 명시적인 대상 선택·재접속·역압력 복원은 기존 동작을 따른다.
새로 받은 상태와 입력을 연결하거나 입력을 자동 재전송하지 않는다.

## 검증

공통 데이터 기대값은 `fixtures/migration/hierarchy-v1.json`, wire 계약은 `contract-v1.json`에 있다.
Rust 표시 모델과 Android에서 실제 사용하는 JSON 디코더·Kotlin 표시 모델이 같은 기대값을 읽는다.
GPUI 자동화는 240/360px 폭·두 테마·긴 한글과 조합 이모지·두 줄/한 줄 제한·메뉴 비겹침,
메타데이터 갱신 후 포커스·펼침 유지와 제목/화살표/메뉴 클릭을 검사한다.

격리 OpenSSH 통합 검사는 두 세션·각 두 창·분할 패널에서 실제 OSC 제목, 숨겨진 대상의 제목·프로세스,
활성 패널 전환, 이름·창 번호 변경, 빈 제목, 수동 새로고침, 재접속과 구독 재등록을 확인한다.
메타데이터 변경 중 Reset/Resize 출력이 없는지, 동일 입력 대상과 원격 PID를 유지하는지,
한 번 보낸 입력이 원격 파일에 한 번만 기록되는지도 검사한다.
실행 결과와 실기 제외 범위는 [VALIDATION.md](VALIDATION.md)의 이번 작업 기록을 따른다.
