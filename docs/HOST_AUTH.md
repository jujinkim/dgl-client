# 데스크톱 호스트 입력과 개인키 가져오기

macOS·Windows 호스트 추가/편집 창은 `연결 정보`와 `인증` 영역으로 나뉜다.
별칭·호스트/IP·포트·사용자 이름·즐겨찾기는 연결 정보에, `비밀번호 / 개인키`
선택과 해당 입력은 인증에 표시한다. 인증 방식을 전환해도 작성한 값과 가져온 키는 유지한다.

## 개인키 가져오기

1. `개인키`를 선택하고 `파일 선택…`을 누른다. 파일 확장자 제한은 없으며
   `id_ed25519`·`id_rsa`처럼 확장자가 없는 키도 선택할 수 있다.
2. 경로를 직접 입력했다면 `경로에서 가져오기`를 누른다. 파일이면 읽고,
   폴더이면 그 폴더에서 선택창을 연다. 빈 입력은 기본 폴더에서 선택창을 연다.
3. 기본 폴더는 Windows `%USERPROFILE%\.ssh`, macOS `~/.ssh`이다.
   `.ssh`가 없으면 사용자 폴더에서 연다. 경로 입력란의 기본 폴더 안내는 실제 입력값이 아니다.
4. 선택한 파일의 전체 경로와 가져온 파일명을 확인한다. 암호화된 키라면 아래의
   `키 암호`를 입력한 뒤 저장한다. 파일 읽기는 최대 128 KiB의 UTF-8 텍스트로 제한하며,
   키 형식·키 암호 검증은 저장 또는 공개키 복사 시 수행한다.

선택창 취소는 기존 경로·가져온 키·암호·상태를 유지한다. 파일 읽기 실패도 기존 키를
바꾸지 않으며, 파일 없음·읽기 권한·크기 초과·빈 파일·인코딩 오류를 구분해 표시한다.
기존 호스트 편집에서 새 키를 가져오지 않으면 보호 저장소의 키를 사용하고,
키 암호를 비우면 저장된 암호를 유지한다. 새 키를 가져오면 입력한 키 암호를 사용한다.

인증 오류는 인증 영역 안에 표시한다. 키가 없으면 `개인키 파일을 먼저 가져오세요`,
키 또는 암호가 잘못되면 `개인키 형식 또는 키 암호를 확인하세요`로 안내한다.
별칭·호스트·포트·사용자 이름 오류는 연결 정보에, 보호 저장소 읽기/쓰기 실패와
호스트 설정 파일 저장 실패는 별도 메시지로 표시한다. 오류를 수정하고 저장을 다시 누를 수 있다.
기존 필수 입력 조건, 코어 공개 API, 호스트·자격 증명 저장 형식은 유지한다.

Windows는 기존 `windows` 의존성의
[Common Item Dialog](https://learn.microsoft.com/en-us/windows/win32/shell/common-file-dialog)를
사용하며 지정 폴더·취소와 실제 API 실패를 구분한다. macOS는 AppKit의
[NSOpenPanel](https://developer.apple.com/documentation/appkit/nsopenpanel)을 사용한다.
Windows 빌드·ZIP·선택적 테스트 절차는 [Windows 안내](WINDOWS.md)를 따른다.

## 호스트키 신뢰 기록

설정 파일의 신뢰 지문은 보호 저장소에 같은 지문이 있을 때만 연결에 사용한다. 이 규칙은
macOS·Windows·Android에 같게 적용한다. 두 기록이 다르거나 보호 저장소 사본이 없으면
처음 연결하는 서버로 취급하지 않고 SSH 연결 전에 차단하며, `설정 > 보안·저장`에서 해당 서버의
신뢰를 삭제하라고 안내한다. 삭제한 뒤 다음 연결에서 서버 지문을 다시 확인하고 신뢰한다.
수동 재접속도 같은 검사를 거친다. 보호 저장소 읽기 실패는 이 안내 대신 보호 저장소 오류로 표시한다.
서버가 신뢰한 지문과 다른 키를 보내면 코어가 인증 전에 `HostKeyChanged`로 차단하고 자동 재시도하지 않는다.

## Windows 실기 확인 (미실행)

- 빈 경로에서 `.ssh`가 열리는지, 해당 폴더가 없으면 사용자 폴더가 열리는지 확인한다.
- 폴더·파일·한글/공백 포함 경로와 확장자 없는 키를 가져온다. 선택창 취소 시 기존 키를 확인한다.
- 파일 없음·읽기 권한 없음·128 KiB 초과·잘못된 키·암호화된 키와 잘못된/올바른 키 암호를 확인한다.
- 인증 전환 후 입력 유지, 새 키 없이 기존 호스트 편집 저장, 오류 수정 후 저장 성공을 확인한다.
- 밝은/어두운 테마와 작은 창에서 스크롤·Tab/Shift+Tab·선택 상태·저장 버튼을 확인한다.
- DPAPI 저장 후 앱을 재실행해 키 인증으로 연결한다. 이 결과는 macOS 테스트로 대체하지 않는다.
